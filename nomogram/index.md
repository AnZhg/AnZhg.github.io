# Nomogram

Nomogram is a Mac app for programming with flowcharts: you build a program as a chart, run it step by step, and export
it as Swift.

- **User manual:** being written.
- **Report a bug:** in Nomogram, choose Help > Report a Bug…, or [open the form](report/bug/). One problem per report,
  please; the steps that show it help most.
- **Report a translation problem:** in Nomogram, choose Help > Report a Translation Problem…, or
  [open the form](report/translation/).
- **Translations:** [the languages, and every string in each](translations/).

You need a GitHub account to report.
